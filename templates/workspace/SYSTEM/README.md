# Organización del sistema

AGENTS.md + ME/ son instrucciones nativas de OpenCode. La fecha y hora viajan
en cada turno, no cambian el encabezado estático. Cada sesión conserva su chat;
la interfaz permite retomarlo. Esto no garantiza una tasa concreta de caché.

Referencia de organización: https://github.com/Cassers/Mi-agente-agent-system
No se distribuyen perfiles personales, instaladores ni corpus UPSTREAM.
La primera conversación guarda preferencias en ME/CONFIG.json con permiso real.
